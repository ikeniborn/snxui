# snxui

GTK4 + Libadwaita graphical client for Check Point SNX VPN on Ubuntu/Debian.
Supports GNOME, KDE Plasma, and XFCE desktop environments.

**Key features:** profile management, OS keyring password storage, system tray with
quick connect/disconnect, XDG autostart, `.deb` and AppImage packaging.
